SMS Sending & Reporting REST API

High-throughput, sub-second latency REST API for Single SMS, Bulk SMS, and Real-time Delivery Reports (DLR).

POST /api/v1/sms/send

1. Single SMS Dispatch API

Send OTPs, transactional alerts, and notifications instantly via high-priority telecom routes.

Request Body (JSON):
{
  "sender_id": "IMMENS",
  "to": "+919768566466",
  "message": "Your security OTP code is 849201. Immense Air",
  "pe_id": "1701158000000000000",
  "template_id": "1707161000000000000"
}
Response Payload:
{
  "success": true,
  "message_id": "MSG-SMS-507804",
  "status": "SUBMITTED",
  "destination": "+919768566466",
  "units": 1,
  "submitted_at": "2026-08-10T12:04:30.434Z"
}
GET /api/v1/sms/report/:message_id

2. SMS Delivery Report (DLR) API

Fetch live status, delivery timestamp, operator route, and latency for any dispatched SMS ID.

Example Request:
GET http://localhost:8080/api/v1/sms/report/MSG-SMS-507804
Response Payload:
{
  "success": true,
  "message_id": "MSG-SMS-507804",
  "sender_id": "IMMENS",
  "destination": "+919768566466",
  "status": "DELIVERED",
  "delivered_at": "2026-08-10T12:04:30.813Z",
  "latency_ms": 377,
  "operator": "Airtel / Jio Direct Route"
}
POST /api/v1/sms/send-bulk

3. Bulk SMS Campaign API

Dispatch high-volume broadcast campaigns to thousands of numbers with a single HTTP POST request.

Request Body (JSON):
{
  "sender_id": "IMMENS",
  "recipients": ["+919768566466", "+918007018757"],
  "message": "Immense Air Special Offer: Get 20% bonus credits today!"
}
GET /api/v1/sms/reports/summary

4. SMS Analytics & Summary API

Fetch overall platform metrics, total delivered count, failure rate, and average latency.

Example Response:
{
  "success": true,
  "total_submitted": 15481,
  "total_delivered": 15457,
  "delivery_rate": "99.85%",
  "avg_latency_ms": 380
}
